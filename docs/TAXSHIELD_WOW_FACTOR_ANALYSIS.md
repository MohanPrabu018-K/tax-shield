# TAXSHIELD WOW-FACTOR ANALYSIS

> Synthetic simulated users were not asked for a WOW answer directly (that would bias the result).
> The WOW ranking is derived from which workflows actually completed end-to-end for every persona
> **and** touch more than one domain at once — i.e. where the product does something the user
> did not have to stitch together manually.

## Rank of distinctive moments (derived from completed persona runs)

1. **One invoice → journal → P&L** — every persona created an invoice and the books updated.
   This is the single strongest differentiator vs "Excel + WhatsApp + accountant".
2. **POS bill → stock moves → GST → journal in one action** (retail) — one scan touches inventory,
   sales tax, and the general ledger.
3. **Tenant-scoped autonomy** — each persona registered and operated a fully isolated account with
   its own parties/products/journals/invoices. Cross-account access returns 404.
4. **Deterministic assistant that actually answers** — "How much tax do I owe?" returns the
   built-up estimate from THIS user's ledger, not a generic essay.
5. **Readiness score + anomalies panel** — "what needs attention" surfaces the thing a small
   business owner did not know to look for.
6. **Practice workflow state machines** (accountant/CA) — client → doc-request → review → overview
   is a coherent loop, not a spreadsheet.
7. **Tenant-isolated, scoped, multi-workspace ready** — 18 accounts, 0 cross-account leakage.
8. **Voice transcribe/synthesize return 200** and accept Tamil / English input.
9. **Month-end close, trial balance, balance sheet, cash flow** all compute from real journals.
10. **Exports**: transactions / invoices / parties / "me" CSV work per-user.

## Primary TaxShield differentiator (from evidence, not assumption)
**The connected ledger**: a normal business action (invoice, POS bill, stock move, payment)
immediately flows into inventory, GST, journals, P&L and the readiness score, scoped to the
user's own account. The assistant then reads from that ledger to answer "how much do I owe /
what do I need to do". This is what a plain accounting app or a spreadsheet does not give a
non-accountant.

## What is NOT the differentiator (expected baseline, not WOW)
- Register / login / profile / sessions — table stakes.
- Basic CRUD for parties, products, transactions.
- Marketing pages, sitemap, SEO, cookie banner.
- Billing trial / test-adapter checkout — operator-confirmed, not "wow".
