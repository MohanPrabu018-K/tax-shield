# SEGMENT FEEDBACK REPORT

> Synthetic simulated-user evaluation. Not real customer validation.
> Based on: 627/627 live API tasks, 14/14 browser journeys (desktop+mobile), voice 200/200.

## Sole proprietors / small businesses (personas 01–03)
- **Average usability**: 4/10 (API 35/35 tasks)
- **Average business value**: invoice→payment→journal→P&L chain worked end-to-end → useful
- **Average trust**: 7/10 (data scoped, reports internally consistent)
- **Top advantages**: connected invoice→accounting→tax flow; dashboard surfacing what needs attention
- **Top problems**: onboarding only stored in localStorage (device switch loses it); terminology (journal/ledger/ITC) is accountant-grade
- **Most valuable workflow**: invoice → payment → reconciliation
- **Most frustrating workflow**: month-end close is a raw data readout, not a guided checklist

## Freelancers / professionals (04–06)
- **Usability**: 4/10
- **Business value**: high for tax-time; low expected weekly
- **Trust**: 7/10
- **Advantages**: TDS + tax payable visibility; evidence-linked documents
- **Problems**: mixed personal/business cash-flow categorization unclear; assistant shallow on open-ended advice
- **Most valuable**: tax estimate + what-needs-attention
- **Most frustrating**: no recurring-expense templates

## Accountants (07–09)
- **Usability**: 3/10 (practice overview is workable but not a full client ledger)
- **Business value**: client/doc-request/review/requests infrastructure exists but thin
- **Trust**: 6/10
- **Advantages**: client + document-request + review state machines are coherent
- **Problems**: no exports yet for staff, no real client portal, CSV export of parties/invoices is basic
- **Most valuable**: practice overview + doc-request/review
- **Most frustrating**: cannot export or hand over a client ledger

## CA firms (10–12)
- **Usability**: 3/10 (same practice surface)
- **Business value**: moderate (compliance visibility across a portfolio)
- **Trust**: 6/10 (needs MFA + audit trail for real adoption)
- **Advantages**: tax-review persona can read calculation + evidence
- **Problems**: no MFA, no real DSC/govt filing, no reports-as-a-package
- **Most valuable**: review workflow + doc requests
- **Most frustrating**: no export package / no ISZzIC visibility

## Retail (13–15)
- **Usability**: 4/10 (POS bill→paid worked, but too many clicks)
- **Business value**: high daily utility for a shop
- **Trust**: 7/10
- **Advantages**: POS→stock→invoice→GST→journal is connected
- **Problems**: credit-note/returns exist only as API (no UI); no barcode/scan; no offline
- **Most valuable**: POS + low-stock guard
- **Most frustrating**: repeated POSENTRY under shop rush is click-heavy

## Individuals (16–18)
- **Usability**: 4/10
- **Business value**: mainly tax-season
- **Trust**: 7/10
- **Advantages**: dashboard + readiness + scenario compare path exist
- **Problems**: no AIS upload flow surfaced in UI; high-complexity person pushes assistant thin
- **Most valuable**: readiness score + tax estimate
- **Most frustrating**: assistant gives deterministic, shallow answers — a real CA is still needed
